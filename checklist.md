# Requirements Review Checklist

## Registration

* [ ] Qeydiyyat prosesi aydın təsvir olunub
* [ ] Required field-lər müəyyən edilib
* [ ] Validation qaydaları qeyd olunub
* [ ] Duplicate qeydiyyat qaydaları göstərilib
* [ ] Error mesajları təsvir olunub

## Duplicate Registration Prevention

* [ ] Təkrar qeydiyyat qaydası müəyyən edilib
* [ ] Unikal identifikatorlar göstərilib
* [ ] Xəbərdarlıq mesajları təsvir olunub
* [ ] Müxtəlif altproqramlar üçün qaydalar qeyd olunub

## Subprogram Eligibility

* [ ] Yaş məhdudiyyətləri göstərilib
* [ ] Minimum yaş tələbi qeyd olunub
* [ ] Maksimum yaş tələbi qeyd olunub
* [ ] Uyğunluq qaydaları tam təsvir olunub

## Candidate Profile

* [ ] Profil sahələri müəyyən edilib
* [ ] Redaktə edilə bilən sahələr göstərilib
* [ ] Məlumatların saxlanılması qaydası qeyd olunub

## Application Tracking

* [ ] Müraciət statusları müəyyən edilib
* [ ] Status dəyişmə qaydaları göstərilib
* [ ] Müraciətdən imtina prosesi təsvir olunub

## Admin Panel

* [ ] Namizəd axtarışı mövcuddur
* [ ] Filtrləmə qaydaları müəyyən edilib
* [ ] Admin funksiyaları təsvir olunub

## Role-Based Access Control

* [ ] Admin səlahiyyətləri müəyyən edilib
* [ ] Köməkçi admin səlahiyyətləri müəyyən edilib
* [ ] İcazəsiz giriş qaydaları göstərilib

## Interview Scoring

* [ ] Bal aralıqları müəyyən edilib
* [ ] Hesablama qaydaları göstərilib
* [ ] Invalid dəyərlər üçün davranış müəyyən edilib

## Notifications

* [ ] Email bildirişləri təsvir olunub
* [ ] SMS bildirişləri təsvir olunub
* [ ] Uğursuz göndəriş halları nəzərə alınıb

## Document Upload

* [ ] CV tələbləri göstərilib
* [ ] Fayl formatları müəyyən edilib
* [ ] Fayl ölçü limiti göstərilib
* [ ] Məcburi və optional sənədlər ayrılıb

## Open Questions

* [ ] Açıq qalan suallar ayrıca sənədləşdirilib
* [ ] Dəqiqləşdirilməli biznes qaydaları qeyd olunub
* [ ] Riskli tələblər müəyyən edilib
