# Requirements Analysis

| Requirement ID | Module / Feature | Requirement | QA Analysis | Testable? | Priority | Notes / Open Questions |
|---|---|---|---|---|---|---|
| REQ-001 | Registration | Namizəd sistem üzərindən qeydiyyatdan keçə bilməlidir. | Qeydiyyat forması valid və invalid məlumatlarla test edilməlidir. | Yes | High | Required field-lər dəqiq müəyyən edilməlidir. |
| REQ-002 | Registration | Qeydiyyat prosesi sadə və aydın olmalıdır. | İstifadəçi lazımsız səhifə yönləndirilmələri olmadan prosesi tamamlamalıdır. | Yes | Medium | UX testləri ilə yoxlanmalıdır. |
| REQ-003 | Registration / Database | Uğurlu qeydiyyatdan sonra namizəd üçün profil yaradılmalıdır. | Qeydiyyatdan sonra profilin avtomatik yaranması və məlumatların saxlanması yoxlanmalıdır. | Yes | High | Profil məlumatlarının hansı sahələrdən ibarət olacağı dəqiqləşdirilməlidir. |
| REQ-004 | Registration / Database | Qeydiyyat məlumatları avtomatik olaraq backend database-ə ötürülməlidir. | Qeydiyyatdan sonra məlumatların sistemdə saxlanması yoxlanmalıdır. | Yes | High | Manual təsdiq addımı olmamalıdır. |
| REQ-005 | Duplicate Registration | Eyni namizəd eyni altproqrama təkrar qeydiyyatdan keçə bilməməlidir. | Təkrar qeydiyyat cəhdi eyni identifikator, email və ya telefon məlumatları ilə test edilməlidir. | Yes | High | Duplicate yoxlamanın hansı məlumat əsasında aparıldığı dəqiqləşdirilməlidir. |
| REQ-006 | Subprogram Selection | Namizəd uyğun olduğu halda bir neçə fərqli altproqrama müraciət edə bilməlidir. | Uyğun namizədin birdən çox altproqram seçməsi test edilməlidir. | Yes | Medium | Paralel müraciətlərin şəxsi kabinetdə necə görünəcəyi dəqiqləşdirilməlidir. |
| REQ-007 | Eligibility Rules | Sistem altproqramlar üzrə yaş məhdudiyyətlərini tətbiq etməlidir. | Minimum, maksimum və sərhəd yaş dəyərləri ilə test aparılmalıdır. | Yes | High | Boundary testing vacibdir. |
| REQ-008 | Cross-Program Restriction | Müəyyən altproqramlar arasında qarşılıqlı məhdudiyyət tətbiq olunmalıdır. | Məhdudlaşdırılmış altproqrama müraciət bloklanmalıdır. | Yes | High | Uğursuz namizəd anlayışı dəqiqləşdirilməlidir. |
| REQ-009 | Candidate Profile | Namizədin əsas məlumatları profil ekranında görünməlidir. | Əlaqə, ünvan, bacarıq və iş təcrübəsi məlumatlarının profildə görünməsi yoxlanmalıdır. | Yes | Medium | Hər sahənin editable olub-olmaması dəqiqləşdirilməlidir. |
| REQ-010 | Candidate Profile | Namizəd icazə verilən məlumatları şəxsi kabinet üzərindən yeniləyə bilməlidir. | Profil update, validation və database update davranışı test edilməlidir. | Yes | Medium | Dəyişiklik tarixçəsinin saxlanılıb-saxlanılmayacağı sual olaraq qalır. |
| REQ-011 | Application Tracking | Namizəd bütün müraciətlərini vahid bölmə üzərindən izləyə bilməlidir. | Müraciətlərin siyahıda görünməsi və statusların göstərilməsi yoxlanmalıdır. | Yes | Medium | Lazımsız bölmələrin silinməsi UI testinə daxildir. |
| REQ-012 | Application Tracking | Namizəd müraciətindən imtina edə bilməlidir. | İmtina əməliyyatı və statusun sistemdə dəyişməsi yoxlanmalıdır. | Yes | High | İmtina üçün confirmation mesajı olmalıdır. |
| REQ-013 | Admin Panel | Admin namizəd məlumatlarını görə və idarə edə bilməlidir. | Admin paneldə data view, search, filter və edit funksiyaları test edilməlidir. | Yes | High | Admin permission-ları ayrıca test olunmalıdır. |
| REQ-014 | Role-Based Access Control | Köməkçi admin yalnız icazə verilən sahələri görə və redaktə edə bilməlidir. | Əsas admin və köməkçi admin üçün fərqli permission testləri aparılmalıdır. | Yes | High | Security baxımından vacib requirement-dir. |
| REQ-015 | Interview Scoring | Admin müsahibə ballarını daxil edə bilməlidir. | Valid, invalid, minimum və maksimum bal dəyərləri test edilməlidir. | Yes | High | Bal aralıqları altproqrama görə dəyişə bilər. |
| REQ-016 | Interview Scoring | Sistem ümumi və ya orta balı avtomatik hesablamalıdır. | Calculation testləri aparılmalıdır. | Yes | High | Hesablama qaydası dəqiq göstərilməlidir. |
| REQ-017 | Candidate Status | Namizəd statusları sistemdə seçilə və saxlanıla bilməlidir. | Status selection, save, display və filter test edilməlidir. | Yes | High | Status dəyişiklikləri üçün audit log sualı açıqdır. |
| REQ-018 | Notifications | Admin namizədə email və ya SMS bildirişi göndərə bilməlidir. | Notification sending, failed sending və mail status test edilməlidir. | Yes | Medium | Retry mexanizmi dəqiqləşdirilməlidir. |
| REQ-019 | Document Upload | Sistem sənəd və CV yükləmə funksiyasını dəstəkləməlidir. | Mandatory və optional upload halları test edilməlidir. | Yes | High | Fayl formatı və ölçü limiti dəqiqləşdirilməlidir. |
| REQ-020 | Document Upload | Bəzi altproqramlarda CV yükləmə məcburi ola bilər. | CV əlavə edilmədən qeydiyyat cəhdi test edilməlidir. | Yes | High | Hansı altproqramlarda məcburi olduğu sənəddə ayrıca göstərilməlidir. |
